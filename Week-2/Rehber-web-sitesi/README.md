# Hakan Kahraman - Kişisel Portfolio Web Sitesi

Bu proje, Hakan Kahraman'ın kişisel portfolio web sitesidir ve sadece HTML kullanılarak geliştirilmiştir. Web sitesi 5 sayfadan oluşmaktadır: Ana Sayfa, Hakkımda, Yetenekler & Deneyimler, İletişim ve Teşekkür sayfası. Projeyi kullanmak için index.html dosyasını web tarayıcısı ile açmanız yeterlidir.
