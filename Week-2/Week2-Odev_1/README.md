# Blog Sitesi Projesi

Bu proje, HTML ve CSS kullanarak oluşturulmuş basit bir blog sitesidir.

## Proje Açıklaması

Proje, bir ana sayfa ve blog gönderisi sayfasından oluşan statik bir blog sitesi içermektedir. Temel web geliştirme teknikleri kullanılarak responsive ve modern bir tasarım uygulanmıştır.

## Dosya Yapısı

```
blog-projesi/
├── index.html      # Ana sayfa
├── post.html       # Blog gönderisi sayfası
├── styles.css      # Stil dosyası
└── README.md       # Proje dokümantasyonu
```

## Kullanılan Teknolojiler

- HTML5
- CSS3

## Özellikler

- Responsive tasarım
- Navigasyon menüsü
- Blog yazısı kartları 
- Tutarlı renk paleti ve tipografi

## Kurulum

1. Projeyi bilgisayarınıza indirin
2. `index.html` dosyasını herhangi bir tarayıcıda açın
