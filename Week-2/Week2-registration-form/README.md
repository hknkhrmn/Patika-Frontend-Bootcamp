Registration Form (Kayıt Formu)

A responsive, custom-designed survey and registration form created as a CSS practice project. This project demonstrates how to create modern, stylish web forms using only core web technologies, without relying on external frameworks like Tailwind, Bootstrap, or JavaScript.

Overview

Purpose: CSS styling practice and form layout design.

Style: Dark green gradient theme with semi-transparent containers.

Structure: Semantic HTML5.

Key Features

Zero Dependencies: Built entirely with Vanilla HTML and CSS.

Custom Design: Unique floating labels, styled radio buttons, and checkboxes created manually with CSS.

Responsive: Adapts to different screen sizes using standard CSS media queries and flexible units.

Visual Effects: Includes gradients, box-shadows, and transitions for interactive elements.

Technologies

HTML5

CSS3

How to Use

Since this project utilizes pure HTML/CSS:

Download the index.html file.

Open it directly in any web browser (Chrome, Firefox, Safari, etc.).
