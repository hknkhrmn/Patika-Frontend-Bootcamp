# Doğan Cüceloğlu - Tribute (Anma) Sayfası

Bu proje, HTML ve CSS eğitimimin 3. haftasında **"Tribute Website Tasarımı"** ödevi (Ödev 2) kapsamında hazırlanmıştır. Saygıdeğer hocamız Prof. Dr. Doğan Cüceloğlu'nun hayatını, eserlerini ve mirasını anlatan, sade ve kullanıcı dostu bir web sitesi tasarladım.

## 🎯 Proje Amacı

Verilen ödev isterlerine uygun olarak, bir edebi figürün hayatını, sözlerini ve kitaplarını içeren, anlamsal (semantic) HTML etiketleri ve CSS stilleri kullanılarak oluşturulmuş bir web sayfasıdır.
